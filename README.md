# 🚀 Smart CRM System

A Full Stack CRM application built using **Spring Boot, React, and MySQL**.

---

## 🧠 Project Description
This CRM system helps manage users, customers, and business data using a layered architecture.

---

## ⚙️ Tech Stack
- Java (Spring Boot)
- React.js
- MySQL
- Spring Data JPA
- REST APIs
- Maven
- Git & GitHub

---

## ✨ Features
- User Registration & Login
- RESTful API architecture
- DTO-based clean design
- Layered architecture (Controller → Service → Repository)
- Database integration with MySQL

---

## 🏗️ Project Structure
- Backend → Spring Boot
- Frontend → React (if added)
- Database → MySQL

---

## ▶️ How to Run
1. Clone repository  
2. Configure MySQL in `application.properties`  
3. Run Spring Boot application  
4. Start frontend (if applicable)
